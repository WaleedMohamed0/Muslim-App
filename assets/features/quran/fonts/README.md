Quran text font

`UthmanicHafs-v-3.0.ttf` is the unmodified KFGQPC Hafs Uthmanic font matched to the bundled Uthmanic text. It includes the open-tanween Quranic glyphs used in the source. The Quran reader uses it for Quran text and Arabic Mushaf labels.

The font's full license is included in `LICENSE-KFGQPC.txt` and embedded in the font metadata. The KFGQPC license permits free use, copying, and distribution with the license; it prohibits selling or modifying the font.

Source: https://text.quran.ws/files/fonts/UthmanicHafs-v-3.0.ttf
