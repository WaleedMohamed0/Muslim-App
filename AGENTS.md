# Repository instructions

## Git changes

- Include every new or modified file needed for the requested work in the final Git change set. In particular, add new files to Git with `git add` so they are tracked and do not remain untracked (often shown in red by Git tools).
- Do not add or stage any `.bin` or `.md` files, or files whose names end in `.lock`, to Git. Leave these files out of the Git change set, even if they appear as modified or untracked.
- Do not stage unrelated pre-existing changes, and do not commit or push unless the user explicitly asks.
